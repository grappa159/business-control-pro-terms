## Как разместить в GitHub Pages

1. Создайте отдельный публичный репозиторий GitHub. Для GitHub Free размещение через Pages доступно в публичном репозитории.
2. Загрузите файл `index.html` в корень репозитория, в ветку `main`. Никакие токены, файлы `.env`, базы или исходный код бота для страницы не нужны.
3. Откройте **Settings → Pages**. В **Build and deployment → Source** выберите **Deploy from a branch**, затем ветку `main` и папку `/ (root)`, нажмите **Save**.
4. После публикации откройте адрес, показанный в Settings → Pages, и проверьте текст и ссылку на бота. Для обычного репозитория адрес обычно `https://ИМЯ-ПОЛЬЗОВАТЕЛЯ.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.
5. Опубликованный HTTPS-адрес уже подготовлен для `PAYMENT_TERMS_URL`. Включайте реальные платежи только после тестовой проверки и отдельного подтверждения владельца.

Справка GitHub: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site
